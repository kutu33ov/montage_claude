# montage_claude

Набор для автоматического монтажа шортсов из разговорных видео: нарезка, вырезка пауз,
вертикальный кадр 9:16, субтитры, ретушь, обложки. Монтирует Claude в облачной сессии.

## Как пользоваться
1. Загрузи видео на Google Drive и открой доступ «Все, у кого есть ссылка».
2. Начни новую сессию Claude Code с этим репозиторием и скинь ссылку.
3. Получишь готовые шортсы (1080×1920), названия и обложки. Правки — просто словами.

## Что умеет
- нарезка на шортсы, вырезка пауз и повторов, склейка кусков из разных мест видео
- вертикальный кадр 9:16 по лицу, наезды камеры на склейках
- субтитры (белые с тонкой обводкой, предлоги не висят в конце строки), заголовок-хук в первые секунды
- лёгкая ретушь кожи и покраснений по зонам (кончик носа, лоб, щёки…)
- бесконечное видео: конец плавно перетекает в начало
- всплывающие крупные надписи («53%»), вставки картинок и сгенерированных графиков с анимацией
- переходы: вспышка, рывок, зум, глитч, тряска — каждый со своим звуком
- звуки: whoosh, swipe, pop, click, ding, riser, boom, glitch
- фоновая музыка, которая автоматически приглушается под голос
- цветокоррекция LUT (warm / cool / contrast / film), прогресс-бар, водяной знак с ником
- обложки с подбором самого чёткого кадра со взглядом в камеру
- громкость под соцсети (−14 LUFS)

Все звуки, музыка-заглушка и LUT-ы сгенерированы с нуля скриптами — без авторских прав.
**Свою музыку** просто клади в `assets/music` — она автоматически используется вместо заглушки.

## Что внутри
| Папка / файл | Что это |
|---|---|
| `CLAUDE.md` | инструкция для Claude: порядок работы и все твои предпочтения по стилю |
| `scripts/prep.py` | скачивание видео, распознавание речи, поиск пауз и лица |
| `scripts/make_short.py` | монтаж шортса: паузы, 9:16, наезды, субтитры, ретушь, громкость |
| `scripts/fx.py` | эффекты: переходы, вставки, надписи, звуки, музыка, LUT, прогресс-бар |
| `scripts/card.py` | генератор графиков и карточек со статистикой |
| `scripts/gen_sfx.py`, `scripts/gen_luts.py` | генераторы звуков, музыки-заглушки и LUT-ов |
| `examples/short_example.json` | пример настройки шортса со всеми эффектами |
| `scripts/skin.py` | ретушь кожи и кончика носа |
| `scripts/pick_frames.py` | подбор самых чётких кадров со взглядом в камеру |
| `scripts/cover.py` | обложки |
| `styles/default.json` | настройки стиля по умолчанию |
| `assets/` | твои звуки, музыка, LUT-ы, оверлеи, картинки, шрифты |

## Куда что класть
- `assets/sfx` — короткие звуки (whoosh, pop, клик) в .mp3/.wav
- `assets/music` — фоновая музыка без авторских претензий
- `assets/luts` — цветокоррекция в формате .cube
- `assets/overlays` — оверлеи и переходы (.mov/.webm с прозрачностью)
- `assets/images` — логотипы, мемы, скриншоты для вставок

Тяжёлые файлы (больше ~50 МБ) лучше держать в папке на Google Drive и давать ссылку.

Шрифт Inter — лицензия SIL OFL 1.1 (`assets/fonts/OFL.txt`).

## Перед каждым видео Claude спросит
1. Сколько секунд должны быть шортсы?
2. Где ретушировать?
3. Вставлять ли графики и что в них указывать?
4. Вставлять ли картинки и какие?
5. Делать ли бесконечное видео (конец перетекает в начало)?
6. Делать ли эффекты переходов?
